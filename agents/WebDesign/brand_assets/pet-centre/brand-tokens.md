# Pet Centre — Brand Tokens

Pulled live from petcentremalta.com (real brand). Use these **exact** values — do not invent brand
colors or substitute fonts. Used by `projects/pet-centre-website/` and any Pet Centre design work.

## Colors
| Token | Hex | Use |
|---|---|---|
| Primary / brand green | `#00975a` | wordmark, primary buttons, headers, key accents |
| Accent gold | `#e0b136` | the two paw prints, highlights, secondary CTAs |
| Deep navy | `#243673` | body text on light, depth, footers |

Derive tints/shades from these (don't reach for default Tailwind green/blue). Tint-shadow rule from
the workspace anti-generic guardrails still applies (layered, low-opacity, color-tinted shadows).

## Typography
- **Display / headings:** *Bobby Jones* (rounded). Web fallback: **Fredoka** (Google Fonts) — closest
  rounded match.
- **Body:** *Montserrat* (primary) or *DM Sans*. Tight tracking on large headings, generous
  line-height (~1.7) on body.

## Logo
Two gold paw prints + green "Pet Centre" wordmark. Original site source asset:
`wp-content/uploads/2023/11/cropped-pet-centreVOCT23GreenBG-Green-1.png` (WordPress/Astra/Elementor).
Get a clean transparent-PNG / SVG export from Riccardo for production use.

## Voice
Warm, caring, local, trustworthy — the strategic spine is care + trust + locality + convenience, not
price/catalogue. See marketing project `projects/pet-centre-marketing/` and memory
`project_pet-centre-mellieha.md`.
