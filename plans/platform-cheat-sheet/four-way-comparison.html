They're four different layers — not four versions of one thing

Comparing them head-to-head on price alone is misleading. Here's what each one actually is:

Web host + builder

Hostinger

Gives you server space, a domain, SSL, and a simple AI builder. A place to run a site — including WordPress/WooCommerce. It is not itself a shop.

Payments + POS

SumUp

A card reader + till + a free light online store. Payments-led: starts from "take a card in person," adds a basic web shop.

All-in-one commerce

Shopify

Hosting + store + POS + payments + security, all managed in one subscription. Nothing to self-administer.

Self-hosted commerce

WooCommerce

A free shop plugin for WordPress. Infinitely flexible, but needs a host (e.g. Hostinger) and someone to run it.

The key relationship: WooCommerce runs on a host like Hostinger — so "Hostinger + WooCommerce" is really one combined route (cheap + flexible, but you own the upkeep). Shopify is the all-in-one managed alternative to that whole stack. SumUp is the odd one out — it's the in-person-first, plug-and-play option.

For your case

Which of the four — Malta shop, in-store + online, perishables, non-coder

Shopify — the only one of the four that's fully managed (you never touch hosting/SSL/PCI/security), runs a real till sharing one stock count with the site, handles perishables via expiry apps, and operates in Malta with 0% cut on Shopify Payments. ≈ €156/mo all-in. The right pick for a non-coder who wants to just run the shop.
SumUp — best budget route (~€107/mo) and just as hands-off, but it's a lighter system with no expiry tracking (you'd keep a spreadsheet) — fine for a small shop, less room to grow.
Hostinger + WooCommerce — the most powerful & flexible, with the best perishable/expiry plugins and 0% cut, but you (or a paid dev) own security, updates and backups — which conflicts with your "the platform must handle security for me" requirement. Only choose it if you'll pay for managed maintenance. Hostinger alone (its own builder) is for a cheap blog/brochure, not a unified shop.
